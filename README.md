# PhotoSwipe

An iPhone app that does one thing well: rapid photo triage.

Enter **delete mode**, see one photo fullscreen at a time, and swipe:

- **Right** → keep
- **Left** → add to the delete list
- **Up** → hide (moves to iOS's Face ID-locked Hidden album)
- **Undo** → step back to the previous photo and change your mind

Nothing is destroyed while you swipe. When you're done, a **Review** screen shows
everything queued for deletion or hiding, lets you rescue anything, and commits all
changes in one batch (iOS asks for a single confirmation).

Start from your newest photo by default, or pick any point in your library and move
backwards or forwards in time.

See the GitHub issues for the build plan.
